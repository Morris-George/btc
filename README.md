# BTC Portfolio

Corporate portfolio website for BTC Group (watches and jewelry in Egypt since 1935).
Static site, no build step: serve the repository root.

- `index.html` and section folders are generated pages
- `assets/` holds CSS, JS and images
- `tools/` holds the Python scripts that generate the pages (`python3 tools/build.py`; it reads the source content, which is not included here)
